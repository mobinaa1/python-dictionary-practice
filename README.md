# Even and Odd Numbers Separator

This is a short Python script to practice dictionaries, loops, and conditional logic. It takes numbers from the user and separates them into even and odd lists inside a dictionary.

## How it works:
1. It creates a dictionary with two empty lists: `"even"` and `"odd"`.
2. It asks the user how many numbers they want to enter.
3. It loops through that number of times, asks for each number, and checks if it is even or odd (using `% 2 == 0`).
4. It appends the number to the correct list and prints the final dictionary.

## What I practiced in this project:
- Using Python **Dictionaries** to store data in key-value pairs.
- Using **For loops** with `range()` based on user input.
- Using the **Modulo operator (`%`)** to check for even or odd numbers.
- Appending items dynamically to lists inside a dictionary.
